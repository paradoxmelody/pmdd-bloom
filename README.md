# PMDD Bloom

Our problem statement is that, we have femtech apps that focus more on  tracking the menstrual cycles of women, but women who suffer from PMDD, already know what is happening in their bodies and why it is happening but they don't know what then to do with all that information. We are building a solution that helps such women better prepare themselves for the cyclical distortion from themselves that comes with living with pmdd, also have support on standby from their support systems, and above that, create a platform that raises awareness of pmdd, and also what it is for those who want to support their loved ones. In future this platform scales from just having the features of planning for pmdd days, reality checker with ai and the suppo t template to a more personalized app that uses user opted in access data to be more tailored to the user, and also it becomes a platform where support from doctors, therapists etc can plug in, and a user can be able to see how different life style choices and medicines improve or not improve their life living with this condition -- It should have  a education qs section e.g what is PMMDS? here is out tech stack:Framework Next.js (App Router) Frontend + API routes in one repo — no CORS setup, no separate FastAPI server to babysit, deploys to Vercel in one command Styling Tailwind CSS Fast to build a calming dark UI without hand-rolling CSS Animation Framer Motion Cheap, high-impact polish for the breathing/grounding UI — this is what makes it feel "designed" not "hackathon-y" AI Claude Haiku 4.5 or Gemini Flash via a single Next.js API route Fast + cheap; keep the key server-side in the route, never in the client State React state + localStorage No database needed for a demo Deploy Vercel free tier One CLI command, live URL for judges -- font to use:Helvetica Now – Neutral, modern, and highly legible and here some judging criteria: 1.
